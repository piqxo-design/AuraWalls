# AuraWalls

AuraWalls is a modern Android wallpaper application built with Kotlin and Jetpack Compose. The goal is to create a fast, beautiful, and production-ready wallpaper app using modern Android development practices.

## Project Overview

AuraWalls focuses on:
- Clean and modern Material 3 UI
- Smooth animations
- High performance
- Offline support
- Scalable architecture
- Easy maintenance

## Tech Stack

- Kotlin
- Jetpack Compose
- Material 3
- MVVM Architecture
- Clean Architecture
- Hilt (Dependency Injection)
- Retrofit (Networking)
- Room (Local Database)
- Coil (Image Loading)
- Coroutines & Flow
